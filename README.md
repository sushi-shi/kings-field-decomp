# King's Field

Binary-matching decompilation of the original Japanese King's Field
(`SLPS-00017`).

Original project contributions are dedicated to the public domain under
[CC0 1.0 Universal](LICENSE), to the extent of the contributors' rights.
This does not grant rights to FromSoftware's game or Sony/Psy-Q material,
including the reconstructed library routines under `src/vendor/`.
Retail game files must be supplied locally; they are not included in this
repository. The Nix environment downloads the historical SDK separately; see
[the toolchain documentation](docs/toolchain.md).

## Quickstart

```sh
nix develop
kf init --retail-dir /path/to/hash-identical/retail
kf build
kf match
kf status
```

`kf build` drives the incremental delink, compile, objdiff, and regression-check
graph. `kf status` is read-only; `kf bank` is the only command that updates the
committed high-water ledger. Use `--image psx|game|open` to focus one linked
program and `kf status --json` for machine-readable output.

## Project

This is three decomps in one repository: the bootstrap `PSX.EXE`, main-game
`GAME.EXE`, and opening `OPEN.EXE`. Each has its own address space, build graph,
and objdiff report. Reconstruction units live in `config/units.toml`; curated
retail functions, data, relocations, and library attribution live under
`config/retail/`.
